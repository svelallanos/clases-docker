Órgano muscular central del sistema cardiovascular. Selecciona una estructura desde el modelo o desde la lista para estudiarla.

FUNCIÓN PRINCIPAL

Mantener la circulación sanguínea pulmonar y sistémica mediante contracciones rítmicas.

RELACIÓN ANATÓMICA

Se ubica en el mediastino, entre ambos pulmones, posterior al esternón y superior al diafragma.
